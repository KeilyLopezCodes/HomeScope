Se diseñaron e integraron los wireframes de baja fidelidad y el flujo de navegación interactivo para la aplicación inmobiliaria HomeScope. 
Este trabajo establece la base y guía visual para el desarrollo del frontend a partir del Sprint 2.

PANTALLAS CLAVE DISEÑADAS CON LA HERRAMIENTA DE FIGMA 
    Pantalla 1: Login / Registro de Usuarios
    Estructura básica para autenticación de usuarios con campos de correo, contraseña y enlace de registro.

    Pantalla 2: Home / Inicio
    Barra de navegación principal, buscador general por zona/dirección y sección de propiedades destacadas.

    Pantalla 3: Catálogo de Propiedades
    Listado en formato grid con espacio para tarjetas de propiedades, filtros laterales (precio, tipo de inmueble) y marcador para el Índice de Conveniencia.

    Pantalla 4: Ficha de Detalle de Propiedad

    Pantalla 5: Formulario de Publicación de Propiedad (Vista Previa)
    Estructura inicial del formulario dividido en pasos (Stepper) para la posterior creación de anuncios por parte del vendedor.

El flujo permite simular el recorrido del usuario desde el inicio de sesión, la búsqueda en catálogo, la consulta de detalles de una propiedad y la navegación hacia el módulo de publicación.
